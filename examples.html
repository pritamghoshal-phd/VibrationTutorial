Worked examples

Each example has the problem statement, an animation of that exact system that you can tune, and a step-by-step solution. Try each problem on paper first, then open one solution step at a time.

The five-step method

  1. Choose a coordinate system: define each coordinate, its positive direction and where it is measured from.
  2. Draw the free-body diagrams of every body, in a displaced position.
  3. Kinetics: write Newton–Euler equations ($\sum F=m\ddot x$, $\sum M_O=I_O\ddot\theta$) for each body.
  4. Kinematics: relate the coordinates through constraints (cables, rolling, links).
  5. Solve: eliminate the unknowns to reach one equation of motion, then answer the question.
