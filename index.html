Linear Vibrations Lab

An interactive companion for the vibrations unit of undergraduate dynamics. Read a little, then play with the simulations: every slider changes a real model, and every plot is computed live from the equations you are learning.

Every parameter has a slider and a box. Type any number into the box (press Enter or click away) to go beyond the slider range, or to try unusual values such as zero, negative damping or negative stiffness. The page explains what happens physically.

How to use this site

Each chapter has a short explanation followed by live simulations. Drag a slider, or type any value into the box beside it, including values beyond the slider range, zero, or negative numbers. The page explains what happens physically when you try something unusual.

Every simulation has Pause, Restart, Default values and a speed menu.
